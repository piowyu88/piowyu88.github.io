# 📁 作品集入口 — 上傳教學

歡迎！這裡是大家放自己 HTML 小作品的地方。上傳完，作品會自動出現在入口首頁上，任何人都能點進去玩。

整個過程**不用裝任何軟體、不用打指令**，全部在瀏覽器裡點一點就好。

---

## 快速版（3 步驟）

1. 打開這個 repo 裡的 `projects` 資料夾
2. 點 **Add file → Upload files**，把你的 HTML 檔案拖進去
3. 檔案要叫 **`index.html`**，而且要放在**你自己的資料夾裡**（例如 `projects/小明的作品/index.html`）

做完按網頁下方綠色的 **Commit changes**，等 1-2 分鐘就上線了。

---

## 詳細步驟

### 1. 進到 projects 資料夾

在這個 repo 的檔案列表裡，點 `projects` 這個資料夾。

### 2. 建立你自己的資料夾（第一次上傳才需要）

點 **Add file → Upload files**。

在上傳畫面裡，把你的 HTML 檔案拖進去之前，先把檔案改名成 `index.html`（如果你的 AI 生成的檔案不是叫這個名字，先在自己電腦上把檔名改掉再上傳）。

接著在上傳區塊上方，會有一個輸入框可以打路徑，打上：

```
你的名字或作品名稱/index.html
```

例如你叫小明，就打 `小明的作品/index.html`。這樣 GitHub 會自動幫你建一個叫「小明的作品」的資料夾，並把檔案放進去。

> ⚠️ **檔名一定要是 `index.html`**，不能是別的名字（例如 `game.html`），不然網站找不到它，會顯示錯誤。

### 3. 提交

把檔案拖進去、路徑打好之後，往下滑，按綠色的 **Commit changes** 按鈕。

### 4. 確認上線

等個 1-2 分鐘，回到入口首頁（網址是這個 repo 的 GitHub Pages 網址），應該就會看到一張新卡片，寫著你的資料夾名稱。點下去就能玩到你上傳的東西。

如果畫面看起來還是舊的、沒看到你的作品，先試試看**強制重新整理**：
- Mac：`Cmd + Shift + R`
- Windows：`Ctrl + Shift + R`

---

## 之後想更新作品怎麼辦？

一樣進到 `projects/你的資料夾/`，點 **Add file → Upload files**，把新版的 `index.html` 拖進去（檔名一樣要叫 `index.html`），GitHub 會直接覆蓋舊的版本，Commit 之後就更新好了。

---

## 常見問題

**Q: 我的作品有好幾個檔案（HTML + CSS + 圖片），怎麼辦？**
A: 全部一起拖進去上傳就好，只要確保主要進入的那個檔案叫 `index.html`，其他檔案（CSS、圖片）名稱不用改，程式裡面引用的路徑記得跟實際檔名對起來。

**Q: 上傳完看不到我的作品？**
A: 先檢查檔名是不是真的叫 `index.html`（大小寫也要對），資料夾路徑有沒有打對；再來試試看強制重新整理瀏覽器。

**Q: 我可以刪掉自己的作品嗎？**
A: 可以，進到你的資料夾，點檔案，右上角垃圾桶圖示，Commit 就會刪除。

**Q: 我可以改別人資料夾裡的東西嗎？**
A: 技術上可以（大家都有上傳權限），但請不要動別人的資料夾，只上傳到自己的那一個。
