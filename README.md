# 📁 作品集入口 — 上傳教學

歡迎！這裡是大家放自己 HTML 小作品的地方。上傳完，作品會自動出現在入口首頁上，任何人都能點進去玩。

整個過程**不用裝任何軟體、不用打指令**，全部在瀏覽器裡點一點就好。

---

## 快速版（3 步驟）

### 前置作業
1. 把你的專案（就是html檔案）改名叫做index.html
2. 創一個資料夾來給你的專案命名，然後把你剛才改名的那個index.html丟進去

### 上傳
1. 打開這個 repo 裡的 `projects` 資料夾
2. 點 **Add file → Upload files**，把你的資料夾拖進去
3. 做完按網頁下方綠色的 **Commit changes**，等 1-2 分鐘就上線了。

### 確認上線

等個 1-2 分鐘，回到入口首頁（網址是這個 repo 的 GitHub Pages 網址），應該就會看到一張新卡片，寫著你的資料夾名稱。點下去就能玩到你上傳的東西。
網址也可以點這個或複製網址 https://piowyu88.github.io/ 。
如果畫面看起來還是舊的、沒看到你的作品，先試試看**強制重新整理**：
- Mac：`Cmd + Shift + R`
- Windows：`Ctrl + Shift + R`

---

## 之後想更新作品怎麼辦？

一樣進到 `projects/你的資料夾/`，點 **Add file → Upload files**，把新版的 `index.html` 拖進去（檔名一樣要叫 `index.html`），GitHub 會直接覆蓋舊的版本，Commit 之後就更新好了。

---

## 常見問題

**Q: 我的作品有好幾個檔案（HTML + CSS + 圖片），怎麼辦？**
A: 資料夾拖進去上傳就好，只要確保主要進入的那個檔案叫 `index.html`，其他檔案（CSS、圖片）名稱不用改。

**Q: 上傳完看不到我的作品？**
A: 先檢查檔名是不是真的叫 `index.html`（大小寫也要對），資料夾路徑有沒有打對；再來試試看強制重新整理瀏覽器。

**Q: 我可以刪掉自己的作品嗎？**
A: 可以，進到你的資料夾，點檔案，右上角垃圾桶圖示，Commit 就會刪除。

**Q: 我可以改別人資料夾裡的東西嗎？**
A: 技術上可以（大家都有上傳權限），但請不要動別人的資料夾，只上傳到自己的那一個。

**Q: 可以改資料夾名字嗎**
A: 可以，進到自己資料夾，點擊那個 `index.html` 然後右上角鉛筆（Edit this file），上面檔名部分，一直刪除，直到刪到資料夾名稱，改完後，要補 `index.html`。
